# Audio Output Toggle

This personal Omarchy bar widget switches all three Arctis Sound Manager
channels—Game, Chat, and Media—between the SteelSeries Arena 7 and Arctis Nova
Pro Wireless while leaving ASM's EQ chain in place.

The widget calls `~/.local/bin/asm-output-toggle`. The command is also usable
directly:

```sh
asm-output-toggle status
asm-output-toggle toggle
asm-output-toggle arena
asm-output-toggle headset
```
